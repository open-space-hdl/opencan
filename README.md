# OpenCAN

OpenCAN is an open CAN network core for spacecraft on-board communication that implements ECSS-E-ST-50-15C (CANbus
extension protocol). It connects a node to a CAN network with a nominal and a redundant bus and provides the
redundancy management, the time distribution and the CANopen services of the standard. The CAN protocol itself (frames,
arbitration, error handling, fault confinement) comes from the CAN 2.0B controller `olo_intf_can` of the Open Logic
VHDL Library. The core is vendor-independent VHDL-2008; buffers use the fault-tolerant entities of
[Open Logic](https://github.com/open-logic/open-logic) (SECDED ECC).

## Status

**In development.** The architecture is defined. The data link (`ocan_link`, nominal and redundant bus), the frame
dispatcher (`ocan_dispatch`), the network management (`ocan_nmt`), the bus redundancy management (`ocan_redundancy`)
and the time distribution (`ocan_time`) are implemented and verified with GHDL; the object dictionary, the SDO server,
the PDOs and the top level follow. The [roadmap](docs/roadmap.md) lists the development phases and the state of every
module.


## Running the tests

Prerequisites: Python 3, [GHDL](https://github.com/ghdl/ghdl) on the `PATH` and the Python packages of
`requirements.txt`.

```shell
git submodule update --init
python -m pip install -r requirements.txt
python run.py -p 8              # full regression with GHDL, 8 parallel simulations
python run.py "*ocan_<module>*" # one module
python run.py --questa <test>   # QuestaSim
```

`run.py` compiles Open Logic into the VHDL library `olo`, the required UVVM components into their own libraries and
all OpenCAN sources into the library `opencan`. `OCAN_GHDL_SIM_FLAGS` passes extra flags to the GHDL simulation, for
example `--vcd=wave.vcd` for a waveform.

Checks besides the regression:

```shell
python lint/lint.py                 # VSG, no errors and no warnings
python run.py --compile-order       # compile_order.txt; the CI fails when the file changes
python -m mkdocs build -f tools/docs/mkdocs.yml  # documentation website, fails on broken links
```

# ocan_mib

Register interface of OpenCAN for a processor system: the AXI4-Lite slave and the register file (MB-1), the event and
error flags with the interrupt and the error counters (MB-2), the PDO data, the mailbox of the application objects and
the local time (MB-3), and the error injection (MB-4). The top level `ocan_axi` connects it to the native ports of
`ocan_core`.

## Tests

```shell
python run.py "*ocan_mib*"
python tools/regmap.py --check
```

| File | Content |
| --- | --- |
| `regs/ocan_regs.yml` | Register map: the one description from which `tools/regmap.py` generates `hdl/ocan_pkg/src/ocan_regs_pkg.vhd`, `docs/register_map.md` and `sw/ocan_regs.h` |
| `src/ocan_mib.vhd` | The register interface: `olo_axi_lite_slave` and the register file |
| `tb/ocan_mib_tb.vhd` | Direct testbench: register accesses through the AXI-Lite VVC of UVVM, the inputs from the core cycle by cycle, a model of the application port of `ocan_od`, a reference model of the register file written from the specification, checked in every cycle and at every read |
| `tb/ocan_mib_th.vhd` | Harness of the direct testbench: the clock, `ocan_mib` and the AXI-Lite VVC master |
| `tb/vunit_config.py` | Configurations of the testbench |
